# Secure Wallet User Guide

Welcome to Secure Wallet, the safe, completely localized way to store your sensitive information.

## Getting Started

When you open Secure Wallet for the first time, you will be prompted to set up FaceID (if supported by your device) or a master PIN code to protect your local database. 

## Features
- **Local Storage:** Your data never leaves your device. Everything is encrypted and stored locally.
- **Biometric Security:** Unlock your wallet quickly using FaceID or TouchID.
- **Document Scanning:** Scan physical documents directly into the app using your device's camera.
- **Media Attachments:** Attach photos and audio recordings to your wallet entries natively.

## Managing Entries
To create an entry:
1. Tap the `+` button in the main screen.
2. Select the category of information (e.g., Credit Card, Password, Document).
3. Fill in the required fields.
4. Attach any necessary media (photos, scans, audio).
5. Save the entry.
